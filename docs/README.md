# Finance Hub

Finance Hub is a personal finance management platform that helps users import bank statements, manage transactions, categorize expenses, and analyze spending habits.

## Features

- User Authentication
- Import bank statements (Excel/CSV)
- Transaction Management
- Expense Categories
- Dashboard & Reports
- Spending Analytics

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Material UI
- TanStack Query

### Backend
- NestJS
- Prisma ORM
- PostgreSQL

### Deployment
- Docker
