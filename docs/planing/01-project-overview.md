# Project Overview

## Goal

Build a scalable personal finance management platform.

## Problem

Managing personal expenses manually is difficult.

Users usually receive transaction data from banks in Excel or CSV format.

Finance Hub allows users to import these files and automatically generate financial reports.

## Target Users

- Personal users
- Freelancers
- Small business owners (future)

## MVP

- Login
- Import bank statement
- View transactions
- Dashboard
- Categories

## Future

- AI Insights
- Budget Management
- Multi-bank Support
- Mobile App
